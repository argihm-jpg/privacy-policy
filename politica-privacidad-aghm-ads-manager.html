Política de Privacidad

Aplicación: AGHM Ads Manager  ·  Última actualización: 26 de marzo de 2026

Esta Política de Privacidad describe cómo AGHM Ads Manager (en adelante "la Aplicación", "yo" o "nosotros") recopila, usa y protege la información cuando utilizas esta aplicación. Al usar la Aplicación, aceptas los términos descritos en este documento.

1. Información que recopilamos

La Aplicación accede a los siguientes datos a través de la API de Marketing de Meta, únicamente con tu autorización explícita:

  • Datos de campañas publicitarias (nombre, estado, presupuesto, resultados)
  • Métricas de rendimiento de anuncios (impresiones, clics, conversiones, gasto)
  • Información de conjuntos de anuncios y creatividades
  • Identificadores de cuenta publicitaria vinculados a tu perfil de Meta

La Aplicación no recopila datos personales de los usuarios finales de tus anuncios, ni accede a mensajes privados, fotos personales u otro contenido ajeno a la gestión publicitaria.

2. Cómo usamos la información

Los datos obtenidos se utilizan exclusivamente para:

  • Analizar el rendimiento de tus campañas publicitarias
  • Generar diagnósticos y recomendaciones de optimización
  • Mostrar reportes y métricas dentro de la Aplicación

Los datos no se venden, ceden ni comparten con terceros bajo ninguna circunstancia.

3. Almacenamiento y seguridad

Los tokens de acceso y credenciales de Meta se almacenan únicamente de forma local en tu dispositivo. La Aplicación no dispone de servidores propios ni bases de datos en la nube donde se guarden tus datos.

Tomamos medidas razonables para proteger la información, sin embargo, ningún sistema es completamente infalible. Eres responsable de mantener seguros tus tokens de acceso.

4. Retención de datos

Los datos de campañas consultados a través de la API se procesan en tiempo real y no se almacenan de forma permanente. Al revocar el acceso de la aplicación desde tu cuenta de Meta, todos los permisos quedan cancelados de inmediato.

5. Tus derechos

En cualquier momento puedes:

  • Revocar el acceso de esta aplicación desde Configuración → Aplicaciones y sitios web en tu cuenta de Facebook
  • Solicitar información sobre los datos que hemos accedido
  • Solicitar la eliminación de cualquier dato almacenado localmente

6. Permisos de Meta utilizados

La Aplicación solicita únicamente los permisos estrictamente necesarios:

  • ads_read — lectura de datos de campañas y anuncios
  • ads_management — gestión de campañas publicitarias
  • business_management — acceso a cuentas de Business Manager

7. Servicios de terceros

La Aplicación utiliza la API de Marketing de Meta para obtener datos publicitarios. El uso de dicha API está sujeto a la Política de la Plataforma de Meta y a los Términos de Servicio de Facebook.

8. Cambios a esta política

Podemos actualizar esta Política de Privacidad ocasionalmente. Cualquier cambio será publicado en esta misma página con una nueva fecha de actualización. Te recomendamos revisarla periódicamente.
